# simple-pong
A simple responsive Pong game built with HTML, CSS, and JavaScript.

## Features
- Left paddle controlled by mouse or arrow keys
- Right paddle controlled by computer by default
- Optional two-player mode using W / S
- Ball collision with walls and paddles
- Scoreboard
- Responsive canvas

## Run locally
Open `index.html` in a browser, or serve it with a simple local server:

```bash
python3 -m http.server 8000
